## 👋 关于我

> **探索人工智能的边界，用工程能力将创意转化为现实。**

你好，我是 **Léo WEE**，目前就读于**上海交通大学信息工程专业**，处于本科阶段。

我关注人工智能与软件工程的交叉领域，尤其是人工智能智能体、生成式人工智能、开发者工具和应用机器学习。

我喜欢把想法变成真正可用的产品：从需求分析、原型设计、编码实现，到测试、文档和持续迭代。我也重视产品体验、结论的可验证性，以及功能边界是否清晰。

**目前关注的方向**

- 🤖 人工智能智能体、智能体技能与工具调用
- 🛠️ 人工智能辅助开发与人机协作工作流
- 🧠 应用机器学习、深度学习与数学建模
- 🌐 人工智能驱动的网页应用与开发者工具
- 🎮 游戏开发、虚拟现实与交互式体验

目前也参与与 **Unity、虚拟现实和生成式人工智能** 相关的科研项目。
